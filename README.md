## ☁️ คู่มือสอนการใช้งาน Supabase สำหรับมือใหม่ (เข้าใจง่ายใน 4 ขั้นตอน)

> **💡 หมายเหตุสำคัญ:** เว็บไซต์นี้มีระบบ **Offline-First (LocalStorage)** อยู่แล้ว คุณสามารถเปิดใช้งาน กรอกวิชา และคำนวณเกรดได้ทันทีโดยที่ข้อมูลไม่หายแม้ยังไม่ได้เชื่อมต่อ Supabase! แต่ถ้าต้องการให้ข้อมูลซิงค์ไปมาระหว่างคอมกับมือถือ สามารถทำตามขั้นตอนนี้ได้เลยค่ะ (ฟรี 100%):

### ขั้นตอนที่ 1: สมัครสมาชิกและสร้างโปรเจกต์
1. เข้าไปที่ [https://supabase.com](https://supabase.com)
2. กดปุ่ม **"Start your project"** หรือ **"Sign in with GitHub"**
3. กดปุ่ม **"New Project"**
4. ตั้งชื่อโปรเจกต์ เช่น `my-cute-timetable` และตั้งรหัสผ่าน Database Password (จดไว้ด้วยนะคะ) จากนั้นกด **"Create new project"**

### ขั้นตอนที่ 2: คัดลอก Project URL และ Anon Key
1. ในหน้าแดชบอร์ดของ Supabase ให้กดไปที่ไอคอนรูปฟันเฟือง **Project Settings** (อยู่แถบเมนูซ้ายล่าง)
2. เลือกเมนูย่อย **"API"**
3. คุณจะเห็น 2 ค่าสำคัญ:
   - **Project URL**: ขึ้นต้นด้วย `https://xxxx.supabase.co`
   - **Project API Keys (anon / public)**: ข้อความยาวๆ
4. นำทั้ง 2 ค่านั้นมาวางในหน้าเว็บของเราที่แท็บ **"⚙️ ธีม & คลาวด์"**

### ขั้นตอนที่ 3: รันคำสั่ง SQL สร้างตาราง (ทำเพียงครั้งเดียว)
1. ในหน้า Supabase ให้กดไปที่เมนู **"SQL Editor"** (ไอคอน `>_` ทางแถบซ้ายมือ)
2. กดปุ่ม **"New Query"**
3. นำโค้ด SQL ด้านล่างนี้ไปวาง แล้วกดปุ่มสีเขียว **"Run"**:

```sql
-- สร้างตารางสำหรับเก็บข้อมูลตารางเรียนและเกรด
CREATE TABLE IF NOT EXISTS student_data (
  id TEXT PRIMARY KEY,
  content JSONB NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- เปิดใช้งานความปลอดภัยและอนุญาตให้อ่านเขียนได้
ALTER TABLE student_data ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public all access" 
ON student_data FOR ALL 
TO anon 
USING (true) 
WITH CHECK (true);
```

*(บนหน้าเว็บในแท็บ "⚙️ ธีม & คลาวด์" มีปุ่มให้กด "📋 คัดลอกคำสั่ง SQL" คลิกเดียวได้ทันที)*

### ขั้นตอนที่ 4: ทดสอบการเชื่อมต่อ
กลับมาที่หน้าเว็บของเรา กดปุ่ม **"🔌 ทดสอบการเชื่อมต่อ"** หากสำเร็จ สถานะมุมบนขวาจะเปลี่ยนเป็น **"🟢 คลาวด์เชื่อมต่อแล้ว"** ข้อมูลทั้งหมดจะถูกซิงค์ขึ้น Supabase คลาวด์ทันที! ☁️✨

## 🌟 สรุปฟีเจอร์เด่นทั้งหมดในเว็บ

1. 📅 **ระบบสร้างตารางเรียน (Timetable Builder)**:
   - กรอกวิชาง่าย: รหัสวิชา, ชื่อวิชา, ห้องเรียน, วัน, เวลาเริ่ม-เลิก, สีประจำวิชา
   - **Smart Autocomplete**: จดจำประวัติสิ่งที่เคยพิมพ์ แค่พิมพ์ตัวอักษรแรกก็มีตัวเลือกโผล่มาให้คลิกเลือก ไม่ต้องพิมพ์ซ้ำ
   - **Time Collision Alert**: แจ้งเตือนเวลาเรียนชนกันอัตโนมัติ
   - **Quick Notes**: คลิกที่กล่องวิชาเพื่อเปิดดูหรือจดโน้ตย่อ/แปะลิงก์ชีทสรุป
   - **Export รูปภาพ**:
     - 📲 **Wallpaper มือถือ (9:16 PNG/JPG)**: สัดส่วนพอดีหน้าจอโทรศัพท์ ไม่โดนนาฬิกาบัง สำหรับตั้งหน้าจอล็อก
     - 💻 **แนวนอน (16:9)**: คมชัดระดับ Retina สำหรับ iPad/คอมพิวเตอร์ หรือพิมพ์
   - **ส่งตารางให้เพื่อน**: เซฟไฟล์ JSON ส่งให้เพื่อนในเซคเปิดในเว็บได้ทันที

2. 📊 **ระบบคำนวณเกรด (GPA & GPAX Engine)**:
   - คำนวณจริงตามมาตรฐานสากลและเกณฑ์ ม.หอการค้าไทย (A=4, B+=3.5, B=3, C+=2.5, C=2, D+=1.5, D=1, F=0 รวมถึง S, U, W, P)
   - แสดง GPA รายเทอม, GPA รวมรายปี, และ GPAX สะสม
   - แถบประเมิน **เกียรตินิยมอันดับ 1 (3.50+)** และ **เกียรตินิยมอันดับ 2 (3.25+)**
   - 🎯 **Target GPA Simulator**: คำนวณเกรดขั้นต่ำที่ต้องทำในเทอมหน้าที่เหลือเพื่อให้ได้เกรดเฉลี่ยสะสมตามเป้าหมาย
   - 💖 **การ์ดสรุปเกรดลง IG Story (9:16)**: ดาวน์โหลดเป็นการ์ดภาพพาสเทลสวยๆ สำหรับแชร์ความภูมิใจลง Instagram Story

3. ⏳ **นับถอยหลังวันสอบ & ส่งงาน (Cute Countdown)**:
   - การ์ดนับถอยหลังสู่วันสอบ Midterm / Final หรือวันส่งโปรเจกต์มาร์เก็ตติ้ง

4. 🤖 **น้องกุลสตรี AI (AI Study & Marketing Buddy)**:
   - วิเคราะห์ภาพรวมตารางเรียนและผลการเรียน
   - ให้คำแนะนำเทคนิคการเรียนของสาขาการตลาดดิจิทัล ม.หอการค้าไทย
   - คำคมสร้างแรงบันดาลใจและพลังบวก
   - รองรับการใส่ Google Gemini API Key สำหรับพูดคุยอิสระ

5. 🎨 **Theme Customizer**:
   - 6 ชุดสีพาสเทลสำเร็จรูป: Strawberry Milk 🍓, Lavender Dream 💜, Matcha Latte 🍵, Peach Sunset 🍑, UTCC Cute Blue 💙, Cloudy Sky ☁️
